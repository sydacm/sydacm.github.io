# Documents 礼文资源

**To add a document:** open one of the folders below → **Add file → Upload files** → drag the PDF in → **Commit changes**. It appears on the Resources page a minute later.

**To remove one:** open the file → the **⋯** menu → **Delete file** → **Commit changes**.

## Naming files

The file name becomes the title on the website, so name it the way you want it to read:

```
01 成人洗礼礼文 Adult Baptism (简体).docx
02 成人洗禮禮文 Adult Baptism (繁體).docx
```

The number at the start sets the order within the folder and isn't shown on the website.

Put `(简体)` or `(繁體)` at the end of the name and the website shows a Simplified or Traditional badge, and lets visitors filter by script.

PDF, Word (.doc/.docx), PowerPoint and Excel files are all accepted.

## Folders

Each folder is a heading on the Resources page. The number at the start sets the order and is not shown. To add a heading, create a new folder (in GitHub: **Add file → Create new file** and type `09 新标题 New heading/placeholder.txt`).

Empty folders are hidden from the website.
